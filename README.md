# Money Finder V10

Customer-facing web app for the Money Finder assessment and personalised Top 3 Money Map.

**Price:** A$19 one-time. No subscription.

## Stack

Next.js (App Router), TypeScript, Tailwind CSS.

## Local development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Notes

- Do not add Stripe secret keys, API keys, or other secrets to source files.
- Do not use real customer data.
- Matching logic will follow the validated Money Finder V9 specification.
